# AFK Auto Sleep

Automatically sleeps while you are AFK. 
`B` (configurable) enables and disables the mod;
you must be targeting a bed when enabling it.
Automatic sleep starts after 30 seconds without movement, camera movement, or relevant input.

`Y` (configurable) opens the client settings. The settings screen controls the
optional multiplayer logout fallback and its chat message. Changes take effect
when saved. The client shows a local warning five seconds before logging out.
